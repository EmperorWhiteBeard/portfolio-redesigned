# Portfolio Redesigned

## ✨ Complete Redesign with Modern UI/UX

Your portfolio has been completely redesigned using modern design principles from Vercel, Linear, and Stripe design systems.

### 🎨 Design Features

**Design System:**
- **DESIGN.md** included with full design tokens and guidelines
- Dark theme (#0a0a0a canvas) with electric blue (#3b82f6) accents
- Sophisticated gradient overlays and glow effects
- Clean typography hierarchy with Inter font family
- Smooth animations and micro-interactions

**All 12 Sections Redesigned:**

1. ✅ **Hero Section** - Animated gradient orbs, profile avatar, social links
2. ✅ **About Section** - Engaging highlight cards with icons and statistics
3. ✅ **Tech Stack Section** - Animated skill bars with 6 categories (Cloud, CI/CD, Containers, IaC, Monitoring, Scripting)
4. ✅ **Projects Section** - Featured project cards with expandable details
5. ✅ **Certifications Section** - Color-coded certification badges with verification links
6. ✅ **Experience Section** - Timeline layout with milestone markers
7. ✅ **Contact Section** - Modern contact form with validation and social links
8. ✅ **Footer** - Professional footer with quick links and branding

**Shared Components:**
- Responsive navbar with smooth scroll
- Scroll progress indicator
- Back-to-top button
- Theme provider (dark mode ready)

### 🚀 Tech Stack

- **Next.js 15** with App Router
- **TypeScript** for type safety
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **Lucide React** for icons

### 📦 Getting Started
